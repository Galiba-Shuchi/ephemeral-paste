# Ephemeral Markdown Paste & Live Previewer

## Project Description
A zero-login code and note-sharing tool that allows users to create, format, preview, and share text through unique URLs.

## Features
- No registration or login required
- Live Markdown preview
- Bold, italic, strikethrough and code formatting
- Unique shareable URL tokens
- Preset and custom expiration time
- Preset and custom view limits
- Automatic view count decrement
- Database transaction for view management
- Expired paste cleanup

## Technologies Used
- PHP
- PostgreSQL
- Supabase
- HTML
- CSS
- JavaScript

## Database
PostgreSQL database hosted on Supabase.

## How to Run
1. Clone or download this repository.
2. Configure your database credentials in `config/db.php`.
3. Start the PHP development server:

```bash
php -S localhost:8000
```

4. Open `http://localhost:8000` in your browser.
